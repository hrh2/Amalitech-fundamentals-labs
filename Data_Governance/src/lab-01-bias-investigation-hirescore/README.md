# Case File 01 — HireScore Bias Investigation

**Format:** Static HTML/CSS/JS data presentation (no build step, no dependencies to install)

## What this is

A visual audit of HireScore AI's candidate-ranking model, translating the written bias
investigation into a browsable "case file": severity stamp, key stats, the four confirmed
bias types, a feature risk chart, an annotated bias pipeline, and a three-phase mitigation
timeline.

## Source material

Built from [`Bias Investigation Report.md`](../../tasks/Bias%20Investigation%20Report.md) (TalentMatch AI / HireScore QA review), reframed
around the Data Governance concepts of **historical bias, sampling bias, measurement bias,
and proxy variables** covered in the course notes.

## Run it

Open `index.html` directly in any browser — everything (fonts, Chart.js) loads from CDN,
nothing needs to be installed or built.
