# Case File 03 — ShopGhana Multi-Jurisdiction Compliance Matrix

**Format:** Static HTML/CSS/JS data presentation (no build step, no dependencies to install)

## What this is

A comparison dashboard for three simultaneous deletion requests to ShopGhana, one under
each regulation: Ghana's DPA (Act 843), the EU's GDPR, and California's CCPA/CPRA. Includes
a deadline comparison chart, a penalty-exposure table, per-customer case tabs (legal rights,
retained data, deadline, drafted response), and a full side-by-side comparison table.

## Source material

Built from [`Multi Jurisdiction Compliance Response Matrix.md`](../../tasks/Multi-Jurisdiction%20Compliance%20Response%20Matrix.md), framed around the course's
data privacy and regulatory-compliance chapters (GDPR Article 17, CCPA opt-out rights,
Ghana DPA retention exemptions).

## Run it

Open `index.html` directly in any browser — fonts and Chart.js load from CDN.
