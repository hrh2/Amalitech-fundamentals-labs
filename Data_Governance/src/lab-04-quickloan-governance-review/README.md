# Case File 04 — QuickLoan Governance Review

**Format:** Static HTML/CSS/JS data presentation (no build step, no dependencies to install)

## What this is

A governance review dashboard for the QuickLoan lending pipeline: a four-item risk register
(data quality, consent/compliance, bias/fairness, reporting), a grouped bar chart of
approval rate by demographic group before/after mitigation, and an annotated data-flow
diagram marking exactly where governance controls (minimization, consent, classification,
cleaning, logging, masking) were added to the pipeline.

## Source material

Built from [`QuickLoan Governance Review Card.md`](../../tasks/QuickLoan%20Governance%20Review%20Card.md), framed around the course's data quality
dimensions, classification framework, and AI governance / fairness metrics chapters.


## Run it

Open `index.html` directly in any browser — fonts and Chart.js load from CDN.
